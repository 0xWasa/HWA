# Security policy

HWA handles NFTs, HYPE and an ERC-20 reward token. Please report suspected vulnerabilities
privately to the repository owner before public disclosure. Do not attach funded private keys,
mnemonics, RPC credentials or relayer secrets to an issue.

The public repository intentionally contains only non-secret addresses, deterministic artifacts,
audit reports and fail-closed deployment tooling. Mainnet activation is a separate Safe-controlled
operation and is not performed by CI.
